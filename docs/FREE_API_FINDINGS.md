## Επίσημες δωρεάν επιλογές που χρειάζονται κλειδί

### Highlightly

- https://highlightly.net/football-api/
- https://highlightly.net/football-api/documentation/box-score/
- https://highlightly.net/football-api/documentation/getting-started/pagination/
- Ο πάροχος δηλώνει Basic free, 100 requests/ημέρα, χωρίς κάρτα, με matches, lineups και player data.
- Το box-score endpoint τεκμηριώνει `minutesPlayed`, βασικό/αναπληρωματικό και στατιστικά ανά παίκτη/αγώνα. Ορισμένα xG πεδία είναι προαιρετικά.
- Odds και geo restrictions δεν είναι διαθέσιμα στο Basic/Free. Το free plan μπορεί να αποκρύπτει ορισμένα αποτελέσματα· χρειάζεται έλεγχος `pagination.totalCount` και `plan.message`.
- Δεν υπάρχει προσωπικό API key στο project. Δεν έγινε authenticated επαλήθευση του ιστορικού EPL/UCL/κυπέλλων/εθνικών. Οι δυνατότητες σε αυτή την ενότητα είναι τεκμηρίωση παρόχου, όχι μετρημένη κάλυψη.

### API-Football

- https://www.api-football.com/pricing
- https://www.api-football.com/documentation_v3
- Free: 100 requests/ημέρα, όλα τα endpoints, με περιορισμούς διαθέσιμων σεζόν.
- Υποψήφιο για fixtures, lineups, coaches, injuries και `fixtures/players` με στατιστικά ανά παίκτη.
- Δεν υπάρχει προσωπικό API key. Πρέπει να ελεγχθεί το `/leagues` για κάθε σεζόν και διοργάνωση και μετά πραγματικά δείγματα από `fixtures/players`.
- Ένα coverage flag δεν εγγυάται πλήρη δεδομένα. Οι τρέχουσες απουσίες δεν συνιστούν αυτόματα ιστορική πληροφορία γνωστή πριν από τις ενδεκάδες.

## Πηγές που δοκιμάστηκαν αλλά δεν κλείνουν το κενό

### TheSportsDB

Επίσημη τεκμηρίωση: https://api.thesportsdb.com/documentation . Με το επίσημο δημόσιο test key `123`, πήραμε HTTP 200 αλλά μόνο:

- 1 ομάδα από την αναζήτηση Arsenal.
- 5 εγγραφές στο επίσημο παράδειγμα lineups.
- 15 αγώνες σε query ολόκληρης Premier League 2024–25, αντί για 380.

Άρα μια HTTP 200 απάντηση δεν σημαίνει πλήρες dataset. Η δωρεάν πρόσβαση δεν κρίθηκε επαρκής για τις ενδεκάδες και το πλήρες ιστορικό που χρειαζόμαστε.

### football-data.org

- https://www.football-data.org/coverage
- https://www.football-data.org/pricing
- Ο ανώνυμος κατάλογος επέστρεψε 190 competitions, αλλά αυτό **δεν** σημαίνει 190 δωρεάν διαθέσιμες διοργανώσεις. Η τεκμηρίωση free αναφέρει 12, μεταξύ άλλων PL, Champions League, World Cup και Euro.
- Η απόπειρα για EPL matches χωρίς token επέστρεψε HTTP 403. Δεν έγινε παράκαμψη.
- Κατάλληλο υποψήφιο για πρόγραμμα/σκορ με δωρεάν λογαριασμό. Το free δεν τεκμηριώνει το λεπτομερές player-minutes ιστορικό που ζητάμε, ενώ Europa League και FA Cup δεν εμφανίστηκαν ως TIER_ONE στον κατάλογο.

### Sofascore

- Επίσημη θέση: https://sofascore.helpscoutdocs.com/article/129-does-sofascore-offer-sports-data-api
- Δηλώνει ότι δεν μοιράζεται data API endpoints λόγω συμφωνιών με παρόχους.
- Η μικρή δοκιμή στο δημόσια αναφερόμενο team-competitions endpoint επέστρεψε HTTP 403. Δεν έγινε αλλαγή ταυτότητας client, χρήση proxy ή παράκαμψη προστασίας.
- Εμπορικά προϊόντα τρίτων με τίτλο «Sofascore API» δεν αποτελούν επίσημο δωρεάν API της Sofascore.

## Απόφαση για το project

1. Δεν χρειάζεται ακόμη να εγκαταλείψουμε τα χαρακτηριστικά συμμετοχής/κούρασης. Αποδείχθηκε ότι τα συγκεκριμένα στοιχεία υπάρχουν και συνδέονται μεταξύ διοργανώσεων.
2. Για μόνιμη πηγή, επόμενη δοκιμή είναι ένα δωρεάν προσωπικό API key Highlightly ή API-Football. Πρώτα ένα μικρό σύνολο ίδιων παλιών αγώνων, μετά έλεγχος τριών σεζόν και πλήρων προγραμμάτων. Δεν απαιτείται πληρωμή για αυτό το πρώτο βήμα.
3. Για ιστορικό value, να εξεταστεί πρώτα η προσβασιμότητα Betfair Basic και η πραγματική κάλυψη επιλεγμένων EPL αγορών. Δεν έχει ακόμη κλείσει αυτό το κενό.
4. Αν δεν καλυφθούν δωρεάν οι ιστορικές αποδόσεις, συνεχίζουμε με αξιολόγηση πιθανοτήτων και μελλοντική καταγραφή αποδόσεων από επιτρεπόμενη πηγή. Χωρίς έγκυρες ιστορικές τιμές δεν θα αναφέρουμε ιστορική κερδοφορία.
5. Οι πραγματικές παλιές συμμετοχές επιτρέπεται να χρησιμοποιούνται μόνο σε προβλέψεις μεταγενέστερων αγώνων. Οι ενδεκάδες του αγώνα-στόχου παραμένουν άγνωστες στο χρονικό όριο της πρόβλεψης.
